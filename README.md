# 📝 Task Manager Web Application

This repository contains a Task Manager web application built using Python, Flask, and SQLAlchemy. The application enables users to create, update, and delete tasks through a simple and responsive interface, helping organize daily activities efficiently.

## 🧪 Project Architecture & Modules

| Module / File | Topic / Role | Core Concepts Implemented |
|--------------|-------------|--------------------------|
| app.py | Backend Controller & Routing | Flask routing, CRUD operations, request handling |
| SQLAlchemy Models | Database Layer | ORM, database schema management |
| templates/ | Frontend Templates | Jinja2 templating, dynamic content rendering |
| static/css/ | UI Styling | Responsive layouts and custom CSS styling |
| requirements.txt | Dependency Management | Python package management |

## ✨ Features

- Add new tasks
- Update existing tasks
- Delete tasks
- Persistent task storage using SQLite and SQLAlchemy
- Simple and responsive user interface

## 🛠️ Tech Stack

- Language: Python
- Web Framework: Flask
- Database: SQLite
- ORM: SQLAlchemy
- Frontend: HTML5, CSS3, Jinja2

## 🚀 How to Run

```bash
git clone <repository-url>
cd TaskManager-HTML-CSS-Flask

python -m venv .venv
.venv\Scripts\activate

pip install -r requirements.txt
python app.py
```

Open your browser and visit:

```text
http://127.0.0.1:5000
```
